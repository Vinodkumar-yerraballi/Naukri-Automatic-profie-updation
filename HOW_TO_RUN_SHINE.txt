SHINE JOB SEARCH AND RESUME UPDATE GUIDE
========================================

Run Shine job search separately from the Naukri search:

   .venv\Scripts\python.exe main.py --search-shine

The command uses roles, locations, posting-age limit, experience range, and
the 75-point default job-to-resume match threshold from
config\job_preferences.yaml. It skips postings with an unknown/older age and
listings where a full job description cannot be verified. For each processed
job it prints the match score. A factual resume draft is generated only when
the score meets the configured threshold; it is saved locally and is not
uploaded or submitted automatically. No applications are submitted.

To generate a reviewable Shine headline/About draft, see
HOW_TO_RUN_PROFILE_TEXT.txt. The supported Shine profile updater changes its
summary from resume-derived text, not from the generated proposal.

Run these commands from the project folder in PowerShell. The examples use
the project's .venv virtual environment.

1. Sign in once and save the local Shine session:

   .venv\Scripts\python.exe main.py --setup-shine-session

   The command opens Shine's sign-in page. Complete login and any OTP/checks,
   then wait until your My Profile page appears and its header no longer
   shows Login before pressing Enter in PowerShell. The resume-upload page
   can load without an authenticated session, so it is not sufficient to
   verify sign-in. Cookies and session storage are saved in
   data\shine_session_state.json to keep the sign-in available to later
   commands. Treat that file and data\shine_browser_profile as sensitive.

2. Replace data\resume.pdf with your updated, text-based resume.

3. Update Shine only:

   .venv\Scripts\python.exe main.py --update-shine-profile

The command uploads the resume when its contents differ from the last
confirmed upload. The upload state is stored in
data\shine_resume_upload.json. It displays the resume-supported profile-field
proposal and updates supported fields only after you type `APPLY`. The
approved update state is stored in data\shine_profile_update.json. The
configured Shine login, upload, and profile-edit URLs are in
config\job_preferences.yaml. The resume upload URL is
https://www.shine.com/myshine/resume/upload. Shine uploads files up to 5 MB.
If Shine changes these pages, open them manually while signed in and update
the corresponding shine_profile URL in config\job_preferences.yaml.

The updater also uses resume-supported details to update Shine's profile
summary and skills. New skills are assigned the configured
`shine_profile.skill_experience` value (currently `0.5 years`); existing
skills are preserved, and Shine's current limit is enforced. Change this
value in `config\job_preferences.yaml` if a different tenure is accurate.
Employment entries are left unchanged when the current form requires job
details that are not present in the resume proposal. Shine's current editor
does not provide supported project or education editors, and the
certification form requires validity information not extracted from the
resume; those sections are left unchanged. Shine's summary editor has a
240-character safe limit, so longer resume-derived summaries are shortened
at a word boundary. Use
`.venv\Scripts\python.exe main.py --update-all-profiles` to force a fresh
check of supported profile fields even if the resume file has not changed.
This command is interactive and must not be scheduled unattended. Complete
sign-in and security checks yourself, and verify the resume and profile
details on Shine after each approved update.
