NAUKRI RESUME AND PROFILE GUIDE
===============================

From the project directory in PowerShell:

   venv\Scripts\python.exe main.py --setup-naukri-session

Sign in yourself in the browser and press Enter in PowerShell. The saved
session is in data\naukri_browser_profile; keep that directory private.

Replace data\resume.pdf with your updated text-based PDF. Run:

   venv\Scripts\python.exe main.py

The app attempts a Naukri resume upload only when the file hash differs from
the last confirmed upload. It records success separately in
data\profile_resume_upload.json. Check your Naukri profile after the run. The
daily command is:

   venv\Scripts\python.exe main.py --schedule

Profile fields such as headline, skills, and work history are not automatically
edited. Run --prepare-profile-update to create a proposal, then review and
apply accurate details yourself. See HOW_TO_RUN.txt for job-search guidance.

The app does not bypass login, CAPTCHA, OTP, or other security checks and
cannot guarantee interviews or shortlisting.
