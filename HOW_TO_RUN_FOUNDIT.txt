FOUNDIT RESUME GUIDE
====================

From the project directory in PowerShell, create a local Foundit session:

   .venv\Scripts\python.exe main.py --setup-foundit-session

Sign in yourself in the opened browser, complete any checks, and press Enter
in PowerShell. The local browser profile is saved in
data\foundit_browser_profile. Keep it private.

This project does not currently search Foundit job listings. Job searches are
available separately for Naukri (--search-naukri) and Instahyre
(--search-instahyre). To generate a reviewable Foundit headline/About draft,
see HOW_TO_RUN_PROFILE_TEXT.txt; the current Foundit editor automation does
not update those fields from that proposal.

Replace data\resume.pdf with your updated text-based PDF. To update Foundit
only, without starting the Naukri job search, run:

   .venv\Scripts\python.exe main.py --update-foundit-profile

The command uploads a changed resume and uses the configured AI provider to
extract resume-supported skills, employment, and projects. It adds missing
entries, updates an existing project's description only if the reviewed
resume proposal differs, and never deletes existing entries. It displays the
proposal and changes supported fields only after you type `APPLY`. The
regular job-pipeline run
can save a proposal but does not apply Foundit field edits. To force a fresh
check on every enabled platform, including Naukri and Shine, even when the
resume file has not changed, run:

   .venv\Scripts\python.exe main.py --update-all-profiles

Confirm the results on Foundit after the command. This feature does not
change Foundit's About/summary field, and it does not search for or apply to
Foundit jobs.

`--update-all-profiles` is interactive and asks you to type `APPLY` for
supported field edits; do not schedule it unattended. For daily headline/About
proposals, follow the Task Scheduler steps in HOW_TO_RUN_PROFILE_TEXT.txt.
Those proposals are not posted automatically.

Resume upload and profile-field updates have separate state files:
data\foundit_resume_upload.json and data\foundit_profile_update.json. If the
site form or AI extraction fails, the command reports the error and does not
mark the profile-field update complete. Check Foundit before retrying.

If the upload reports that it could not confirm success, inspect the resume
shown on Foundit before running the command again. The upload state is saved
only after confirmation, so a retry may upload the same file again.

If Groq returns HTTP 403, check the API key, account/model access, and any
network or provider restrictions in Groq's official console. The local
Ollama fallback uses the configured model and can take up to three minutes
for profile extraction; confirm Ollama is running with
`ollama list`. The resume is sent to Ollama on this computer when the local
fallback is used.

Foundit login, CAPTCHA, OTP, and verification checks must be completed by you.
The app does not overwrite existing work or project records, and it does not
apply to jobs on Foundit. It cannot guarantee interviews or shortlisting.

The normal main.py command also attempts configured platform updates, then
continues into the Naukri job search. Use --update-foundit-profile when you
want Foundit without opening the Naukri pipeline.
