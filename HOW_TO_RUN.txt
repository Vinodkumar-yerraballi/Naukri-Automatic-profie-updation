JOB PIPELINE AND RESUME UPDATES - QUICK COMMAND GUIDE
=====================================================

Open PowerShell and move to the project folder:

   cd "C:\Users\vinod\OneDrive\Desktop\Naukri-Automatic-profie-updation"

Use the commands below from this folder. The project virtual environment is
named ".venv".


COMMANDS YOU WILL USE
---------------------

1. Save or refresh your local Naukri sign-in session (run once, or if login
   has expired):

   .venv\Scripts\python.exe main.py --setup-naukri-session

   Sign in yourself in the browser window, complete any verification, return
   to PowerShell, and press Enter. Never put your Naukri password in a file.

2. Save or refresh separate local sessions for each platform:

   .venv\Scripts\python.exe main.py --setup-foundit-session
   .venv\Scripts\python.exe main.py --setup-indeed-session
   .venv\Scripts\python.exe main.py --setup-shine-session
   .venv\Scripts\python.exe main.py --setup-hirist-session
   .venv\Scripts\python.exe main.py --setup-wellfound-session

   Sign in yourself in each browser window and press Enter. Never put account
   passwords in a file. The browser profiles are stored under data\.

3. Create a profile-field proposal from your current source resume:

   .venv\Scripts\python.exe main.py --prepare-profile-update

   The proposal is saved at:

   data\processed\profile_update_proposal.json

4. Run one job search now, attempt to upload a changed source resume, and
   review pending jobs interactively:

   .venv\Scripts\python.exe main.py

   Keep the PowerShell window open and available for input. If
   application.auto_apply is true, approving a job with A can trigger a
   supported one-step Apply action on Naukri. Review the job and resume
   carefully before approving.

   To search Naukri explicitly:

   .venv\Scripts\python.exe main.py --search-naukri

   To search Instahyre separately:

   .venv\Scripts\python.exe main.py --search-instahyre

   To search Shine separately:

   .venv\Scripts\python.exe main.py --search-shine

   Shine results are scored against your resume. Listings with unknown/old
   posting ages or without a full job description are skipped. The default
   draft threshold is a 75% job-to-resume match, configurable in
   config\job_preferences.yaml. No applications are submitted.

   Job-search adapters currently exist for Naukri, Instahyre, and Shine.
   Foundit, Indeed, Hirist, and Wellfound do not yet search listings.

   To update an individual platform without starting the Naukri job search:

   .venv\Scripts\python.exe main.py --update-foundit-profile
   .venv\Scripts\python.exe main.py --update-indeed-profile
   .venv\Scripts\python.exe main.py --update-shine-profile
   .venv\Scripts\python.exe main.py --update-hirist-profile
   .venv\Scripts\python.exe main.py --update-wellfound-profile
   .venv\Scripts\python.exe main.py --update-naukri-profile

   To update every enabled platform at once:

   .venv\Scripts\python.exe main.py --update-all-profiles

   Indeed, Hirist, and Wellfound currently upload resumes only. Naukri and
   Foundit update supported headline/skills/projects or skills/work-history/
   projects; Shine updates summary, skills, and supported work details.
   Profile fields not listed here are not automated.

5. Start the daily job/resume pipeline:

   .venv\Scripts\python.exe main.py --schedule

   The configured schedule is 09:00 Asia/Kolkata. Keep the laptop on, awake,
   connected to the internet, and the PowerShell window open.


UPDATE YOUR RESUME ON SUPPORTED PLATFORMS
-----------------------------------------

1. Update your master resume and export it as a text-based PDF.
2. Replace this project file with the updated PDF:

   data\resume.pdf

3. Sign in to each platform once using the setup commands above. To have the
   app attempt the changed-resume upload, run:

   .venv\Scripts\python.exe main.py

   The normal run compares the PDF with the last confirmed upload and attempts
   an upload only when it has changed. It uses separate browser sessions and
   state files for each enabled platform. If a site asks for
   login/verification or does not confirm the upload, check that profile
   manually before retrying. The profile-proposal command does not upload the
   PDF or change profile fields.


UPDATE PROFILE FIELDS
---------------------

The normal and scheduled runs can prepare resume-supported field proposals,
but do not apply profile-field edits. The explicit `--update-<platform>-profile`
commands display the proposal and apply supported fields only after you type
`APPLY`. Existing records are preserved; no project or work-history record is
deleted. Naukri supports headline, key skills, and adding missing projects.
Foundit supports skills, work experience, and adding missing projects.
Shine supports summary, skills, and selected work details. Indeed, Hirist, and
Wellfound currently upload the resume only.

Use --prepare-profile-update to create a Naukri JSON proposal for manual
review without opening the profile editor. Open
data\processed\profile_update_proposal.json and check every detail against
your real experience.

To configure and generate daily headline/About text proposals, edit the
per-platform headline_prompt and about_prompt values under
profile_text_updates.platforms in config\job_preferences.yaml. Use the same
AI provider and API key configured for resume tailoring, then run one platform
at a time or all enabled platforms:

   .venv\Scripts\python.exe main.py --generate-profile-text naukri
   .venv\Scripts\python.exe main.py --generate-profile-text foundit
   .venv\Scripts\python.exe main.py --generate-profile-text indeed
   .venv\Scripts\python.exe main.py --generate-profile-text instahyre
   .venv\Scripts\python.exe main.py --generate-profile-text shine
   .venv\Scripts\python.exe main.py --generate-profile-text hirist
   .venv\Scripts\python.exe main.py --generate-profile-text wellfound
   .venv\Scripts\python.exe main.py --generate-profile-text all

Review the dated JSON under data\processed\profile_text and copy approved
text to your profile yourself. The generator saves used headlines in
data\profile_text_history.json, avoids generating a second proposal on the
same date, and rejects repeated headlines. It does not publish profile
changes. See HOW_TO_RUN_PROFILE_TEXT.txt for Windows daily-task setup and
platform limitations.

To change the roles and skills used by this project's job matching, edit:

   config\profile.yaml

To change search locations, experience range, schedule time, application
limit, and related preferences, edit:

   config\job_preferences.yaml

Changing these YAML files changes the app's search/matching preferences. It
does not itself change the corresponding fields on Naukri.

The configured job search covers Data Analyst, Data Scientist, Business
Intelligence, reporting, and related machine-learning roles. It prioritizes
searching every configured role each run, rotates locations when the daily
search limit is reached, and passes the configured experience and posting-age
filters to Naukri (currently 0-2 years and posted within 24 hours). It
processes up to 20 listings per run. Edit job_search.max_jobs_per_run,
posted_within_hours, and max_searches_per_run in
config\job_preferences.yaml to change these limits.


REVIEW AND APPLY FOR JOBS
-------------------------

The application settings are in config\job_preferences.yaml:

   application:
     mode: review
     auto_apply: true
     maximum_applications_per_day: 15

With auto_apply set to true, the interactive command is:

   .venv\Scripts\python.exe main.py

For each pending job, inspect the job details and draft, then choose:

   A = approve this job; the app may attempt its supported one-step Apply
   R = reject this job
   S = skip for now
   Q = exit the review queue

Approval is per job. The app may attempt an application only when it can
identify one clear Apply or Apply now action on a matching Naukri job page.
It stops rather than automating multi-step forms, external application sites,
or uncertain page states. It does not bypass login, CAPTCHA, OTP, or other
verification.

The tailored DOCX and plain-text drafts are saved locally under
data\processed\resumes; they are not automatically attached to the Naukri
application. Naukri uses the resume already on your profile. Check Naukri
after each attempt. If the app reports
an unconfirmed result, verify the application on Naukri before trying again.
The configured daily limit counts confirmed and uncertain attempts.

IMPORTANT: --schedule runs the pipeline without an interactive review prompt.
It searches and can attempt a changed-resume upload, but does not run the
approval queue and does not submit applications. For applications that need
your approval, use "python main.py" in an interactive PowerShell window and
approve each job yourself.


ABOUT MATCH AND ATS SCORES
--------------------------

The configured matching.minimum_score is this project's job-relevance score.
It is not an ATS score. Different employers and applicant systems use
different criteria, so the project cannot guarantee or manufacture a 75-95%
ATS score, an interview, or a job offer. The configured 75 threshold selects
jobs by relevance. Keep all resume and profile details truthful and review
both generated draft formats before using them.
