NAUKRI PROFILE AND JOB PIPELINE - QUICK COMMAND GUIDE
====================================================

Open PowerShell and move to the project folder:

   cd "C:\Users\vinod\OneDrive\Desktop\Naukri-Automatic-profie-updation"

Use the commands below from this folder. The project virtual environment is
named "venv".


COMMANDS YOU WILL USE
---------------------

1. Save or refresh your local Naukri sign-in session (run once, or if login
   has expired):

   venv\Scripts\python.exe main.py --setup-naukri-session

   Sign in yourself in the browser window, complete any verification, return
   to PowerShell, and press Enter. Never put your Naukri password in a file.

2. Create a profile-field proposal from your current source resume:

   venv\Scripts\python.exe main.py --prepare-profile-update

   The proposal is saved at:

   data\processed\profile_update_proposal.json

3. Run one job search now, attempt to upload a changed source resume, and
   review pending jobs interactively:

   venv\Scripts\python.exe main.py

   Keep the PowerShell window open and available for input. If
   application.auto_apply is true, approving a job with A can trigger a
   supported one-step Apply action on Naukri. Review the job and resume
   carefully before approving.

4. Start the daily job/resume pipeline:

   venv\Scripts\python.exe main.py --schedule

   The configured schedule is 09:30 Asia/Kolkata. Keep the laptop on, awake,
   connected to the internet, and the PowerShell window open.


UPDATE YOUR RESUME ON NAUKRI
----------------------------

1. Update your master resume and export it as a text-based PDF.
2. Replace this project file with the updated PDF:

   data\resume.pdf

3. To have the app attempt the upload, run:

   venv\Scripts\python.exe main.py

   The normal run compares the PDF with the last confirmed upload and attempts
   an upload only when it has changed. It requires the saved Naukri session.
   Complete login or verification yourself if prompted, then check your
   Naukri profile to confirm the resume was updated.

You can also upload the PDF yourself on Naukri. The profile-proposal command
does not upload the PDF.


UPDATE YOUR NAUKRI PROFILE FIELDS
---------------------------------

The app does not automatically edit the Naukri headline, desired job title,
summary, skills, employment, education, projects, or certifications.

1. Generate a proposal using the command above.
2. Open data\processed\profile_update_proposal.json and check every detail
   against your real experience and resume.
3. Sign in to Naukri and open your profile's edit page.
4. Copy only accurate details into the matching Naukri fields and save them
   yourself. For example, set your desired job title to Data Scientist if
   that is the role you want. The proposal may suggest a separate headline.
5. Review the profile after saving.

To change the roles and skills used by this project's job matching, edit:

   config\profile.yaml

To change search locations, experience range, schedule time, application
limit, and related preferences, edit:

   config\job_preferences.yaml

Changing these YAML files changes the app's search/matching preferences. It
does not itself change the corresponding fields on Naukri.


REVIEW AND APPLY FOR JOBS
-------------------------

The application settings are in config\job_preferences.yaml:

   application:
     mode: review
     auto_apply: true
     maximum_applications_per_day: 15

With auto_apply set to true, the interactive command is:

   venv\Scripts\python.exe main.py

For each pending job, inspect the job details and draft, then choose:

   A = approve this job; the app may attempt its supported one-step Apply
   R = reject this job
   S = skip for now
   Q = exit the review queue

Approval is per job. The app may attempt an application only when it can
identify one clear Apply or Apply now action on a matching Naukri job page.
It stops rather than automating multi-step forms, external application sites,
or uncertain page states. It does not bypass login, CAPTCHA, OTP, or other
verification.

The tailored DOCX draft is saved locally under data\processed\resumes; it is
not automatically attached to the Naukri application. Naukri uses the resume
already on your profile. Check Naukri after each attempt. If the app reports
an unconfirmed result, verify the application on Naukri before trying again.
The configured daily limit counts confirmed and uncertain attempts.

IMPORTANT: --schedule runs the pipeline without an interactive review prompt.
It searches and can attempt a changed-resume upload, but does not run the
approval queue and does not submit applications. For applications that need
your approval, use "python main.py" in an interactive PowerShell window and
approve each job yourself.


ABOUT MATCH AND ATS SCORES
--------------------------

The configured matching.minimum_score is this project's job-relevance score.
It is not an ATS score. Different employers and applicant systems use
different criteria, so the project cannot guarantee a 90% ATS score, an
interview, or a job offer. Keep all resume and profile details truthful and
review AI-generated content before using it.


PRIVACY
-------
