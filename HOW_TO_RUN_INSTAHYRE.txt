INSTAHYRE JOB SEARCH GUIDE
=========================

From the project directory in PowerShell, check the search roles and
locations in config\job_preferences.yaml, then run:

   .venv\Scripts\python.exe main.py --search-instahyre

This opens Instahyre's public job-search page, selects each configured role
and location search, and adds visible job listings to the same local job
database used by the Naukri review queue. It uses the configured
max_searches_per_run and max_jobs_per_run limits.
The configured location "Remote" is selected using Instahyre's "Work From
Home" location option.
Listings without experience information are retained in the local review
queue; listings with a stated experience range outside your configured range
are still skipped.

The command is search-only. It does not apply to jobs, change profile data,
or require an Instahyre login for public listings. If Instahyre asks for a
security check, complete it yourself in the browser and retry. The search
filters and listing-card selectors may need updates if Instahyre changes its
page.

Instahyre searches are opt-in and do not run as part of python main.py or the
daily Naukri scheduler. Review collected listings in the local job queue
before taking any action.

To generate a reviewable headline/About proposal for Instahyre, see
HOW_TO_RUN_PROFILE_TEXT.txt. This proposal is not posted to Instahyre.
