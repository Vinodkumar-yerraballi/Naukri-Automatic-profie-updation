Company career jobs: run and review

Inputs
- C:\Users\vinod\Downloads\company_india_jobs.json (company grouped source)
- C:\Users\vinod\Downloads\company_india_jobs_flat.json (1,233 job URLs used by the scraper)

Output files
- data\reports\company_careers_jobs.xlsx: descriptions, composite scores, matched/missing skills, resume skill coverage, company summary, and scrape errors
- data\reports\company_careers_matches_over_70.json: jobs scoring strictly above 70%, plus scrape errors

Run from the project folder in PowerShell
1. .\.venv\Scripts\python.exe main.py --search-company-careers
2. .\.venv\Scripts\python.exe scripts\retry_company_careers_errors.py  (optional: retries prior failures)
3. .\.venv\Scripts\python.exe scripts\export_company_careers_json.py

The scraper reads public job URLs listed in config\company_careers.json under settings.seed_jobs_file. The current path points to company_india_jobs_flat.json. The grouped JSON contains the corresponding company/job source data and summary.

Scores use config\profile.yaml and config\job_preferences.yaml. Resume Skill Coverage (%) is a separate skills-only comparison against data\resume.pdf. Jobs at exactly 70% are excluded; only scores above 70% appear in the JSON. Inaccessible URLs and invalid placeholders are recorded in the Excel and JSON scrape_errors list.
